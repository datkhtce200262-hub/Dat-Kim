# DatK AI Portfolio

Website portfolio tĩnh dùng HTML, CSS và JavaScript, thiết kế cho hồ sơ ứng tuyển AI Engineer Intern.

## Chạy trên máy
1. Tải hoặc giải nén thư mục này.
2. Mở `index.html` bằng trình duyệt. Có thể dùng VS Code với tiện ích Live Server để xem trong lúc chỉnh sửa.

## Đăng lên GitHub Pages
1. Tạo một repository mới trên GitHub, ví dụ `datk-ai-portfolio` (đổi tên tùy ý).
2. Tải các file `index.html`, `style.css`, `script.js` và thư mục `assets` lên repository.
3. Mở **Settings → Pages**.
4. Trong phần **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn branch `main`, thư mục `/(root)`, rồi nhấn **Save**.
6. Đợi GitHub Pages triển khai xong. URL thường có dạng `https://USERNAME.github.io/REPOSITORY/`.

## Việc cần cá nhân hóa trước khi nộp
- Kiểm tra tên, email, ngày tốt nghiệp và nội dung kỹ năng.
- Thay các dòng “Mã nguồn: cập nhật sau” bằng URL repository dự án thật.
- Thay hình minh họa bằng ảnh dự đoán/biểu đồ được tạo từ chính notebook. Hình minh họa hiện tại là đồ họa CSS, không phải kết quả thực nghiệm.
- Bổ sung các chỉ số đánh giá đã xác minh; không tự điền số liệu chưa đo.
- Có thể thêm liên kết CV PDF ở phần Liên hệ.
- Nếu chưa có GitHub repository cho từng dự án, hãy tạo và hoàn thiện README trước khi đưa liên kết lên website.

## Cấu trúc
- `index.html`: nội dung website
- `style.css`: giao diện responsive
- `script.js`: menu trên màn hình nhỏ và năm hiện tại
- `assets/`: thư mục để thêm ảnh thật của dự án
